**Stack:** Next.js, React, Supabase, Leaflet/OpenStreetMap, OAuth

**Play it:** [manhunt-mu.vercel.app](https://manhunt-mu.vercel.app)

A real-time location game built from scratch, with live GPS tracking and a competitive points and challenge system. It has served **60+ users with 40 playing at once** at peak.

### Features

- **Rooms:** Kahoot-style rooms where an admin creates a game, sets challenges and map boundaries, and invites players with a shareable code
- **Live map:** Leaflet/OpenStreetMap overlays with real-time player positions and live bus routes and schedules pulled in by polling
- **Accounts:** Supabase for auth (OAuth), accounts, and challenge management
