**Stack:** Next.js, React, Supabase, Leaflet/OpenStreetMap, OAuth

**Play it:** [manhunt-mu.vercel.app](https://manhunt-mu.vercel.app)

A real-time location-based game with live GPS tracking, an interactive map with admin-configurable boundaries, and a competitive points and challenge system. It has served **250+ users with 80 playing at once** at peak.

### Features

- **Rooms:** Kahoot-style rooms where an admin creates a game, sets challenges, and invites players with a shareable code
- **Live map:** Leaflet/OpenStreetMap with real-time player locations, interactive overlays, and live bus route and schedule polling
- **Accounts:** Supabase for user accounts, challenge management, and OAuth

The map-boundary feature and the interface were both reworked based on player feedback. Deployed on Vercel.
