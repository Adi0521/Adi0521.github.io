**Stack:** Next.js, TypeScript, Tailwind, FastAPI, SQLAlchemy, Supabase Postgres

**Code:** [github.com/Adi0521](https://github.com/Adi0521) <!-- swap in the repo URL -->

A social platform for chefs, built with a 6-person team.

- **Backend (my focus):** a FastAPI + SQLAlchemy API on Postgres, with separate profile, recipe, review, follow, and friendship tables for quick updates
- **Frontend:** built with teammates in Next.js and TypeScript: recipe feed, recipe detail and add-recipe modals, rankings, and profiles, with JWT-based auth
- Deployed on Vercel
